  <h2 style="color: #333; margin-top: 0;">Project Overview</h2>
  <p style="color: #444; line-height: 1.6;">
    BUYE is a mobile-first financial technology application built for African citizens, prioritizing the Ghanaian market. It democratizes access to quality products by bridging the gap between consumer purchasing power and affordable credit, empowering users to shop immediately and pay later through secure, manageable installments.
